Sofi & Ely Calendar

Shared calendar for Sofi (סופי) and Ely (איליי), November 2026 – January 2027.

Open it: https://sofiasuton.github.io/sofi-ely-calendar/

Sign in with Google. Only Sofi's and Ely's accounts can see or edit it (enforced by the Firestore security rules).
Changes sync live between both of you through Firebase (Firestore). The page itself holds no events.
Works offline with the last saved copy and syncs when back online.
